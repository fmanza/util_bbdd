# Migración DDL SQL Server como origen

## Objetivo

Migrar la estructura completa de un schema SQL Server a Oracle, MariaDB o PostgreSQL: generar el
script DDL y, opcionalmente, aplicarlo directamente contra el servidor destino.

## Requisitos

- `util_bbdd` instalado con el driver del motor destino (`oracledb`, `mariadb-connector`/`aiomysql`,
  `psycopg2`/`psycopg3`)
- Conexión SQL Server con permisos de lectura sobre `INFORMATION_SCHEMA` y `sys.*`
- Driver SQL Server compatible: **pymssql** (param style `%(name)s`) o pyodbc con wrapper
- Opcional: conexión al motor destino activa para ejecución directa

---

## SQL Server → Oracle

```python
from util_bbdd import SyncDatabaseManager, MigrationPlanner
from util_bbdd.migrate import format_plan_text

sqlserver_manager = SyncDatabaseManager(
    connection_string="mssql+pymssql://user:pass@sql-host:1433/ventas",
)

planner = MigrationPlanner(
    source_engine="sqlserver",
    target_engine="oracle",
)

plan = planner.plan(connection=sqlserver_manager, schema="dbo")
print(format_plan_text(plan))

with open(plan.suggested_filename(), "w", encoding="utf-8") as f:
    f.write(plan.emit_ddl())
```

### Extracto del script Oracle

```sql
CREATE TABLE "CLIENTES" (
  "ID" NUMBER(10,0) NOT NULL,
  "NOMBRE" VARCHAR2(200),
  "FECHA_ALTA" DATE,
  CONSTRAINT "PK_CLIENTES" PRIMARY KEY ("ID")
);

CREATE SEQUENCE "CLIENTES_SEQ" START WITH 1 INCREMENT BY 1 NOCACHE NOCYCLE;
CREATE OR REPLACE TRIGGER "TRG_CLIENTES"
  BEFORE INSERT ON "CLIENTES" FOR EACH ROW
BEGIN
  IF :NEW."ID" IS NULL THEN
    SELECT "CLIENTES_SEQ".NEXTVAL INTO :NEW."ID" FROM DUAL;
  END IF;
END;
```

### Oracle 12c+: columnas IDENTITY nativas

```python
planner = MigrationPlanner(
    source_engine="sqlserver",
    target_engine="oracle",
    oracle_identity_mode="identity_by_default_on_null",  # requiere Oracle 12c+
)
plan = planner.plan(connection=sqlserver_manager, schema="dbo")
# Las columnas IDENTITY emiten GENERATED BY DEFAULT ON NULL AS IDENTITY
```

## SQL Server → MariaDB

```python
from util_bbdd import SyncDatabaseManager, MigrationPlanner
from util_bbdd.migrate import format_plan_text

sqlserver_manager = SyncDatabaseManager(
    connection_string="mssql+pymssql://user:pass@sql-host:1433/ventas",
)

planner = MigrationPlanner(
    source_engine="sqlserver",
    target_engine="mariadb",
    charset="utf8mb4",
    collation="utf8mb4_unicode_ci",
)

plan = planner.plan(connection=sqlserver_manager, schema="dbo")
print(format_plan_text(plan))

with open(plan.suggested_filename(), "w", encoding="utf-8") as f:
    f.write(plan.emit_ddl())
```

### Extracto del script MariaDB

```sql
CREATE TABLE `CLIENTES` (
  `ID` INT(11) NOT NULL AUTO_INCREMENT,
  `NOMBRE` NVARCHAR(200),
  `FECHA_ALTA` DATETIME2,
  CONSTRAINT `PK_CLIENTES` PRIMARY KEY (`ID`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## SQL Server → PostgreSQL

```python
from util_bbdd import SyncDatabaseManager, MigrationPlanner
from util_bbdd.migrate import format_plan_text

sqlserver_manager = SyncDatabaseManager(
    connection_string="mssql+pymssql://user:pass@sql-host:1433/ventas",
)

planner = MigrationPlanner(
    source_engine="sqlserver",
    target_engine="postgresql",
    pg_schema="ventas",   # opcional; emite SET search_path = ventas;
)

plan = planner.plan(connection=sqlserver_manager, schema="dbo")
print(format_plan_text(plan))

with open(plan.suggested_filename(), "w", encoding="utf-8") as f:
    f.write(plan.emit_ddl())
```

### Extracto del script PostgreSQL

```sql
SET search_path = "ventas";

CREATE TABLE "clientes" (
  "id" SERIAL NOT NULL,
  "nombre" VARCHAR(200),
  "fecha_alta" TIMESTAMP,
  CONSTRAINT "PK_clientes" PRIMARY KEY ("id")
);
```

## Revisar avisos del plan

```python
from util_bbdd import MigrationPlanner
from util_bbdd.migrate import format_plan_markdown

planner = MigrationPlanner(source_engine="sqlserver", target_engine="postgresql")
plan = planner.plan(connection=sqlserver_manager, schema="dbo")

# Avisos individuales
for w in plan.warnings:
    if w.severity in ("ERROR", "WARNING"):
        loc = f"{w.table}.{w.column}" if w.column else w.table
        print(f"[{w.severity}] {loc}: {w.message}")

# Reporte Markdown completo
report = format_plan_markdown(plan)
with open("ventas_migration_report.md", "w", encoding="utf-8") as f:
    f.write(report)
```

## Notas de operación

- Las columnas `IDENTITY(1,1)` de SQL Server se convierten a `AUTO_INCREMENT` (MariaDB),
  `SERIAL`/`BIGSERIAL` (PostgreSQL) o `SEQUENCE+TRIGGER` / `GENERATED AS IDENTITY` (Oracle)
- Tipos `VARCHAR(MAX)` / `NVARCHAR(MAX)` se convierten a `CLOB` (Oracle), `LONGTEXT` (MariaDB)
  o `TEXT` (PostgreSQL)
- Las vistas se incluyen en el script con el SQL T-SQL original; revisar manualmente
  funciones como `GETDATE()`, `ISNULL()`, `TOP`, etc.
- `VIEW_DEFINITION` puede truncarse a 4000 chars en SQL Server < 2019
- Identificadores > 30 chars se truncan con sufijo hash en Oracle (límite Oracle 12.1)
- FKs circulares se emiten como `ALTER TABLE ADD CONSTRAINT` al final del script
- Stored procedures y funciones se emiten verbatim con aviso de revisión manual
