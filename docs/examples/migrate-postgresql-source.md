# Migración DDL PostgreSQL como origen

## Objetivo

Migrar la estructura completa de un schema PostgreSQL a Oracle, MariaDB o SQL Server: generar el
script DDL y, opcionalmente, aplicarlo directamente contra el servidor destino.

## Requisitos

- `util_bbdd` instalado con el driver del motor destino (`oracledb`, `mariadb-connector`/`aiomysql`,
  `pymssql`)
- Conexión PostgreSQL con permisos de lectura sobre `INFORMATION_SCHEMA` y `pg_catalog`
- Driver PostgreSQL compatible: **psycopg2** o **psycopg3** (param style `%(name)s`)
- Opcional: conexión al motor destino activa para ejecución directa

---

## PostgreSQL → Oracle

```python
from util_bbdd import SyncDatabaseManager, MigrationPlanner
from util_bbdd.migrate import format_plan_text

pg_manager = SyncDatabaseManager(
    connection_string="postgresql+psycopg2://user:pass@pg-host:5432/ventas",
)

planner = MigrationPlanner(
    source_engine="postgresql",
    target_engine="oracle",
)

plan = planner.plan(connection=pg_manager, schema="public")
print(format_plan_text(plan))

with open(plan.suggested_filename(), "w", encoding="utf-8") as f:
    f.write(plan.emit_ddl())
```

### Extracto del script Oracle

```sql
CREATE TABLE "CLIENTES" (
  "ID" NUMBER(10,0) NOT NULL,
  "NOMBRE" VARCHAR2(200),
  "EMAIL" CLOB, -- CHARACTER VARYING sin límite → CLOB
  "FECHA_ALTA" TIMESTAMP,
  CONSTRAINT "PK_CLIENTES" PRIMARY KEY ("ID")
);

CREATE SEQUENCE "CLIENTES_SEQ" START WITH 1 INCREMENT BY 1 NOCACHE NOCYCLE;
CREATE OR REPLACE TRIGGER "TRG_CLIENTES"
  BEFORE INSERT ON "CLIENTES" FOR EACH ROW
BEGIN
  IF :NEW."ID" IS NULL THEN
    SELECT "CLIENTES_SEQ".NEXTVAL INTO :NEW."ID" FROM DUAL;
  END IF;
END;
```

### Oracle 12c+: columnas IDENTITY nativas

```python
planner = MigrationPlanner(
    source_engine="postgresql",
    target_engine="oracle",
    oracle_identity_mode="identity_by_default_on_null",  # requiere Oracle 12c+
)
plan = planner.plan(connection=pg_manager, schema="public")
# Las columnas SERIAL/BIGSERIAL emiten GENERATED BY DEFAULT ON NULL AS IDENTITY
```


### Extracto del script MariaDB

```sql
CREATE TABLE `clientes` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `nombre` VARCHAR(200),
  `email` LONGTEXT, -- character varying sin límite → LONGTEXT
  `activo` TINYINT(1),
  `fecha_alta` DATETIME(6),
  CONSTRAINT `PK_clientes` PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## PostgreSQL → SQL Server

```python
from util_bbdd import SyncDatabaseManager, MigrationPlanner
from util_bbdd.migrate import format_plan_text

pg_manager = SyncDatabaseManager(
    connection_string="postgresql+psycopg2://user:pass@pg-host:5432/ventas",
)

    source_engine="postgresql",
    target_engine="sqlserver",

print(format_plan_text(plan))

with open(plan.suggested_filename(), "w", encoding="utf-8") as f:
    f.write(plan.emit_ddl())
```

```sql
  [id] BIGINT NOT NULL IDENTITY(1,1),

  [activo] BIT,
  [fecha_alta] DATETIME2(6),
```

## Revisar avisos del plan

```python
from util_bbdd import MigrationPlanner
from util_bbdd.migrate import format_plan_markdown

planner = MigrationPlanner(source_engine="postgresql", target_engine="oracle")
plan = planner.plan(connection=pg_manager, schema="public")

# Avisos individuales
for w in plan.warnings:
    if w.severity in ("ERROR", "WARNING"):
        loc = f"{w.table}.{w.column}" if w.column else w.table
        print(f"[{w.severity}] {loc}: {w.message}")

# Reporte Markdown completo
report = format_plan_markdown(plan)
with open("ventas_migration_report.md", "w", encoding="utf-8") as f:
    f.write(report)
```

## Notas de operación

- Columnas `SERIAL`/`BIGSERIAL`/`SMALLSERIAL` (detectadas por `nextval(...)` en `COLUMN_DEFAULT`)
  se convierten a `AUTO_INCREMENT` (MariaDB), `IDENTITY(1,1)` (SQL Server) o
  `SEQUENCE+TRIGGER` / `GENERATED AS IDENTITY` (Oracle)
- `character varying` sin longitud explícita (`char_length=NULL`) → `CLOB` (Oracle),
  `LONGTEXT` (MariaDB), `NVARCHAR(MAX)` (SQL Server)
- `BOOLEAN` → `NUMBER(1,0)` en Oracle con aviso `WARNING`
- `JSON`/`JSONB` → `CLOB`/`LONGTEXT`/`NVARCHAR(MAX)` con aviso `WARNING`
- Las vistas se incluyen con el SQL PostgreSQL original; revisar funciones como
  `NOW()`, `COALESCE`, `EXTRACT`, `GENERATE_SERIES`, etc.
- Índices no-PK extraídos via `pg_catalog.pg_index` (compatible con PostgreSQL 8.4+)
- Identificadores > 30 chars se truncan con sufijo hash en Oracle (límite Oracle 12.1)
- FKs circulares se emiten como `ALTER TABLE ADD CONSTRAINT` al final del script
- Stored procedures y funciones se emiten verbatim con aviso de revisión manual
