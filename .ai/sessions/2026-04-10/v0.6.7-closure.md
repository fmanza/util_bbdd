## Breaking Changes

⚠️ **Migration Required** for consumers:

### Removed Facades (Legacy)
```python
# Before (v0.6.6)
from util_bbdd.database_exceptions import DatabaseConnectionError
from util_bbdd.database_queries import DatabaseQueries
from util_bbdd.database_type_validator import DatabaseTypeValidator
from util_bbdd.driver_validator import DriverValidator

# After (v0.6.7)
from util_bbdd import ConnectionError, DatabaseQueries, DatabaseTypeValidator, DriverValidator
```

### Removed Exception Aliases
| Old Name | New Name |
|----------|----------|
| DatabaseConnectionError | ConnectionError |
| DatabasePoolError | PoolConnectionError |
| DatabasePoolTimeoutError | PoolTimeoutError |
| DatabaseError / UtilBbddError | DatabaseException |

### Removed Protocol Aliases
| Old Name | New Names |
|----------|-----------|
| SourceAdapter | SourceAdapterSync / SourceAdapterAsync |
| RoutineAdapter | RoutineAdapterSync / RoutineAdapterAsync |

**Migration path**: Full mapping in CHANGELOG.md
