## AI output summary

### Análisis

El emitter Oracle documentaba que Oracle 12c+ soporta `GENERATED AS IDENTITY`, pero emitía
el patrón clásico `CREATE SEQUENCE + CREATE OR REPLACE TRIGGER` por compatibilidad con Oracle 11g.
La semántica del trigger (`IF :NEW.COL IS NULL THEN SELECT NEXTVAL...`) equivale exactamente
a `GENERATED BY DEFAULT ON NULL AS IDENTITY`: inserciones manuales permitidas, generación
automática si la columna se omite o recibe `NULL`.

### Diseño adoptado

| Decisión | Alternativa | Razón |
|---|---|---|
| Modo `"sequence_trigger"` por defecto | Cambiar a identity | Compatibilidad hacia atrás con Oracle 11g y tests existentes |
| `"identity_by_default_on_null"` en lugar de `"always"` | `GENERATED ALWAYS` | `ALWAYS` bloquearía inserciones manuales, rompiendo semántica actual |
| `OracleIdentityMode` TypeAlias exportado | Literal inline | Permite re-uso en planner sin duplicar el tipo |
| `_VALID_ORACLE_IDENTITY_MODES` frozenset importado en planner | Hardcodeado en planner | Fuente única de verdad; fallos tempranos en `MigrationPlanner.__init__` |
| `GENERATED ... AS IDENTITY` antes de `NOT NULL` | Después | Orden correcto según sintaxis Oracle DDL |

### IMPLEMENT

**`emitters/oracle.py`**
- `OracleIdentityMode = Literal["sequence_trigger", "identity_by_default_on_null"]` — tipo exportado.
- `_VALID_ORACLE_IDENTITY_MODES: frozenset[str]` — constante de validación.
- `OracleDDLEmitter.__init__(oracle_identity_mode="sequence_trigger")`:
  valida contra `_VALID_ORACLE_IDENTITY_MODES`; guarda en `self._identity_mode`.
- `_emit_column`: cuando `col.auto_increment and self._identity_mode == "identity_by_default_on_null"`,
  inserta `GENERATED BY DEFAULT ON NULL AS IDENTITY` entre el tipo y `NOT NULL`.
- `_emit_sequences_and_triggers`: devuelve `[]` inmediatamente en modo `identity_by_default_on_null`.

**`planner.py`**
- Importa `OracleIdentityMode` y `_VALID_ORACLE_IDENTITY_MODES` de `oracle.py`.
- `MigrationPlanner.__init__`: nuevo parámetro `oracle_identity_mode="sequence_trigger"`;
  validado con `_VALID_ORACLE_IDENTITY_MODES` para fail-fast al construir el planner.
- `self._oracle_identity_mode` almacenado y pasado a `OracleDDLEmitter(oracle_identity_mode=...)`
  en `_plan_from_mariadb`, `_plan_from_sqlserver`, `_plan_from_postgresql`.
