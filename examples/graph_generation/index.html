Ejemplo: Generación de Grafos de Relaciones¶

1. Contexto del Ejemplo¶

Introspecciona las claves foráneas de un esquema y genera grafos SVG/PNG que muestran las relaciones entre tablas. Útil para documentar la estructura de una base de datos sin escribir DDL manualmente.

Resuelve la necesidad de comunicar el modelo de datos a equipos de arquitectura, auditoría o soporte sin exponer las credenciales ni requerir acceso directo a la BD.

Dependencia opcional

Requiere el extra analysis (pip install "util_bbdd[analysis] @ git+https://github.com/fmanza/util_bbdd.git@v5.2.0") y los binarios de Graphviz instalados en el sistema (dot en PATH).

2. Implementación de Referencia¶

"""
Graph Generation — Visualizar relaciones entre tablas

Este ejemplo muestra cómo:
1. Introspeccionar metadatos
2. Generar grafo de relaciones
3. Exportar a SVG/PNG
4. Configurar profundidad y dirección
"""

from util_bbdd import SyncDatabaseManager
from util_bbdd.analysis import GraphvizRelationshipGraphExt


def demonstrate_graph_generation():
    """Generar grafo de relaciones."""

    # 1. Conectar a BD
    manager = SyncDatabaseManager(db_type="sqlite", conn_params={"database": ":memory:"})

    # Crear esquema de ejemplo
    manager.execute_custom_many(
        """
        CREATE TABLE users (
            id INTEGER PRIMARY KEY,
            name TEXT
        )
    """
    )

    manager.execute_custom_many(
        """
        CREATE TABLE orders (
            id INTEGER PRIMARY KEY,
            user_id INTEGER,
            created_at TEXT,
            FOREIGN KEY(user_id) REFERENCES users(id)
        )
    """
    )

    manager.execute_custom_many(
        """
        CREATE TABLE items (
            id INTEGER PRIMARY KEY,
            order_id INTEGER,
            product_name TEXT,
            FOREIGN KEY(order_id) REFERENCES orders(id)
        )
    """
    )

    print("Esquema creado: users -> orders -> items\n")

    # 2. Obtener metadatos
    tables = manager.get_tables()
    table_names = [t.name for t in tables]
    print(f"Tablas encontradas: {table_names}\n")

    # 3. Generar grafo paginado por tabla
    from pathlib import Path

    graph = GraphvizRelationshipGraphExt(
        db_manager=manager,
        show_columns=True,
        show_data_types=True,
        max_depth=2,
    )

    print("Generando grafos paginados...\n")

    # 4. Generar archivos SVG
    print("Exportando a formatos:")

    output_dir = Path("./graphviz_output")
    output_dir.mkdir(exist_ok=True)

    graph_files = graph.generate_graphviz_graph_paginated_ext(
        table_name="users",  # Tabla raíz
        output_dir=output_dir,
        format="svg",  # O "png", "pdf"
        max_subnodes=10,
        show_columns=True,
    )

    for file in graph_files:
        print(f"   {file}")
    print()

    # 5. Visualizacion ASCII
    print("Visualizacion ASCII:")
    print(
        """
        users
          |
          | (1:N)
          v
        orders
          |
          | (1:N)
          v
        items
    """
    )

    # 6. Información del grafo
    print("Informacion del grafo:")
    print("   - Tabla raíz: users")
    print("   - Profundidad máxima: 2 niveles")
    print("   - Tablas: 3 (users, orders, items)")
    print("   - Relaciones: 2 (users -> orders, orders -> items)")

    manager.close()


if __name__ == "__main__":
    demonstrate_graph_generation()

3. Explicación del Código¶

Aspectos críticos:

  • max_depth: controla cuántos saltos de FK se incluyen desde la tabla raíz. Valores > 3 generan grafos ilegibles en esquemas complejos.
  • LevelDirection: OUTGOING muestra tablas hijas (las que la tabla referencia); INCOMING tablas padre (las que la referencian); BOTH ambas.
  • Paginación automática: si max_subnodes se configura y la tabla tiene muchas relaciones, el módulo genera múltiples imágenes numeradas automáticamente.
  • pipe_* vs generate_*: los métodos pipe_* retornan bytes sin escribir en disco (útil para embeber en aplicaciones web); los generate_* escriben directamente al sistema de archivos.

4. Ejecución y Pruebas¶

# Instalar extra de análisis
pip install "util_bbdd[analysis]"

# Instalar binarios Graphviz del sistema (Linux/macOS)
# apt install graphviz / brew install graphviz

# Validación sintáctica
python -m py_compile docs/examples/graph_generation.py

# Ejecución (requiere BD con FKs definidas)
python docs/examples/graph_generation.py

Los ficheros SVG/PNG se generan en el directorio de salida configurado.
