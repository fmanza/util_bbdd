Comparador de Esquemas¶

API para comparar estructuras entre dos bases de datos e introspeccionar diferencias.

SchemaComparator¶

SchemaComparator() ¶

Compara dos esquemas de base de datos usando sqlalchemy.engine.Inspector.

Soporta tablas, columnas, índices, foreign keys, vistas, comentarios y, opcionalmente, routines (procedures/functions) cuando el Inspector o el engine del caller lo permitan.

Inicializa SchemaComparator con logger.

compare(source, target, *, source_schema=None, target_schema=None, include_tables=True, include_views=True, include_indices=True, include_foreign_keys=True, include_comments=True, include_routines=False, source_label=None, target_label=None, on_progress=None, cancel_token=None) ¶

Compara dos esquemas y devuelve las diferencias encontradas.

Comparar procedures/functions vía catálogo del motor. Nota: No todos los motores soportan introspección de routines. - MariaDB, MySQL, Oracle, SQL Server, PostgreSQL: ✓ Soportado - HSQLDB: ✗ No soportado (DDL no portable); include_routines=True será ignorado con warning. - SQLite: N/A (sin routines)

Etiqueta del origen en el SchemaDiff, el log, los informes y el nombre de sus ficheros. None usa motor [schema] (p. ej. oracle [ESQ_ORIGEN]), sin host, puerto, usuario ni ruta.

 None
target_label str | None

Etiqueta del destino; mismas reglas que source_label.

 None
on_progress ProgressCallback | None

Recibe los ProgressEvent de la operación "compare": fase "metadata" (lectura por lotes de las tablas comunes: 0, 1 y 2 de 2 lados), "tables" (0 de N al empezar y uno por tabla común, con su nombre), "views" y "routines" (0 y 1 de 1). Solo las fases incluidas.

 None

Parada cooperativa: se comprueba al empezar cada fase, entre los dos lados de la lectura y entre tablas. Lanza OperationCancelledError (no hay SchemaDiff parcial).

 None

Returns:

Type Description
SchemaDiff

SchemaDiff con todas las diferencias encontradas.

Raises:

Type Description
OperationCancelledError

cancel_token cancelado.
Rendimiento

Los metadatos de las tablas comunes (columnas, PK, índices, FKs y comentarios) se leen con Inspector.get_multi_*: una consulta por schema y tipo en PostgreSQL y Oracle; en SQL Server PK, índices, FKs, comentarios y columnas con consultas por schema (metadata.reflection); en MariaDB/MySQL, cinco consultas por schema en lugar de un SHOW CREATE TABLE por tabla (H-29); en SQLite, PRAGMA tabla a tabla (en proceso, sin red).

Vistas y routines: definiciones con una consulta por lado y tipo de objeto desde el catálogo de metadata/ (ADR-003, C4); antes una consulta por vista y lado, y un SHOW CREATE por routine en MariaDB/MySQL. include_*=False evita las consultas de lo que no se compara.

Número total de diferencias de primer nivel.

total_leaf_differences property ¶

Número total de diferencias hoja (columnas, índices, FKs, comentarios, vistas, routines).

to_dict() ¶

Serializa el diff a tipos JSON (dict, list, str, bool, None).

El resultado lleva format y format_version y se reconstruye exacto con :meth:from_dict (SchemaDiff.from_dict(diff.to_dict()) == diff). Las tuplas se escriben como listas.

Example

import json diff = SchemaDiff(source_label="pg [public]", target_label="ora [APP]") SchemaDiff.from_dict(json.loads(json.dumps(diff.to_dict()))) == diff True

from_dict(data) classmethod ¶

Reconstruye un diff escrito por :meth:to_dict.

Se ignoran las claves que no son campos (las que añada una versión posterior compatible); los campos con valor por defecto pueden faltar.

Raises:

Type Description
SchemaDiffValidationError

format o format_version desconocidos, falta un campo obligatorio o un valor no tiene el tipo esperado (con la ruta del valor: table_diffs[2].status).
