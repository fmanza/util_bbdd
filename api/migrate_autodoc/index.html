Migración DDL¶

MigrationPlanner traduce el esquema de un motor a DDL de otro y devuelve un MigrationPlan. Referencia curada por motor de origen: Oracle, MariaDB, SQL Server, PostgreSQL, MySQL y vistas.

MigrationPlanner¶

MigrationPlanner(source_engine='oracle', target_engine='mariadb', charset=DEFAULT_CHARSET, collation=DEFAULT_COLLATION, number_fallback='DOUBLE', engine='InnoDB', int_display_width=11, sql_server_collation=None, pg_schema=None, oracle_identity_mode='sequence_trigger', view_strategy='auto') ¶

Orquestador de migración DDL entre motores.

Parameters:

Name Type Description Default
source_engine str

Motor origen ("oracle", "mariadb", "mysql", "sqlserver" o "postgresql").

 'oracle'
target_engine str

Motor destino ("mariadb", "mysql", "sqlserver", "postgresql" o "oracle").

 'mariadb'
charset str

CHARACTER SET (solo aplica cuando target_engine es "mariadb" o "mysql").

 DEFAULT_CHARSET
collation str

COLLATE (solo aplica cuando target_engine es "mariadb" o "mysql"). Con destino "mysql", el valor por defecto (utf8mb4_uca1400_ai_ci, exclusivo de MariaDB) se sustituye por utf8mb4_0900_ai_ci; una collation que MySQL no tenga lanza ValueError.

 DEFAULT_COLLATION
number_fallback NumberFallback

Tipo destino para NUMBER Oracle sin precisión (solo cuando source_engine="oracle").

 'DOUBLE'
engine str

Motor de almacenamiento (solo aplica cuando target_engine es "mariadb" o "mysql").

 'InnoDB'
int_display_width int

Display width para INT en MariaDB (default: 11). Usar 0 para emitir solo INT sin paréntesis. Solo aplica cuando source_engine="oracle" y target_engine="mariadb" (con destino "mysql" el emitter quita el ancho de los enteros, obsoleto en MySQL 8, salvo TINYINT(1)).

 11
sql_server_collation str | None

COLLATE a nivel columna para SQL Server (opcional). Si None, no se emite cláusula COLLATE (usa collation de la BD destino).

 None
pg_schema str | None

Schema PostgreSQL (opcional). Si se indica, emite SET search_path = schema; al inicio del script DDL.

 None
view_strategy ViewStrategy

Cómo se migra el SQL de las vistas. "auto" (por defecto) lo reescribe al dialecto destino con sqlglot si está instalado (extra util_bbdd[migrate]) y, si no, lo copia sin reescribir; "transpile" exige sqlglot; "passthrough" lo copia sin reescribir (comportamiento hasta 0.19.0). Una vista que no se puede reescribir de forma fiable se copia sin reescribir, con aviso.

 'auto'

Raises:

Type Description
ValueError

Si source_engine o target_engine no están soportados, si source_engine == target_engine, si charset/collation no son válidos para MariaDB, si engine no es un nombre de motor de almacenamiento válido (destino MariaDB/MySQL) o si view_strategy no es válida.
ImportError

Si view_strategy="transpile" y sqlglot no está instalado.

plan(connection, schema) ¶

Extrae y transforma el esquema origen, produciendo un MigrationPlan.

El catálogo se lee con la MetadataSource del origen (una consulta por tipo de objeto, ADR-003), descartando lo que tuviera en caché para schema: el plan refleja siempre el catálogo actual.

Parameters:

Name Type Description Default
connection Any

SyncDatabaseManager del motor origen (se usa su metadata_source) o una MetadataSource (p. ej. CatalogSource.from_engine(engine)).

 required
schema str

Nombre del schema/owner/database a migrar. Para SQL Server corresponde a TABLE_SCHEMA (ej. 'dbo').

 required

Returns:

Type Description
MigrationPlan

MigrationPlan listo para emit_ddl() o execute().

MigrationPlan¶

MigrationPlan(tables, warnings, source_schema, source_engine, target_engine, emitter, views=list(), routines=list()) dataclass ¶

Plan de migración ejecutable: contiene tablas transformadas, warnings y configuración.

error_count property ¶

Número de warnings con severidad ERROR.

warning_count property ¶

Número de warnings con severidad WARNING.

info_count property ¶

Número de warnings con severidad INFO.

emit_ddl() ¶

Genera el script DDL completo para el motor destino.

Incluye tablas (con índices y FKs), vistas y rutinas. Algunos emisores descubren warnings solo durante la emisión (p.ej. un DEFAULT con forma de función no reconocida, MIG-03); self.warnings se actualiza con ellos tras generar el DDL.

emit_statements() ¶

Genera la lista de sentencias DDL individuales (sin ';').

Incluye tablas (con índices y FKs), vistas y rutinas. Algunos emisores descubren warnings solo durante la emisión (p.ej. un DEFAULT con forma de función no reconocida, MIG-03); self.warnings se actualiza con ellos tras generar las sentencias.

execute(target_connection, *, audit_sink=None) ¶

Ejecuta el DDL generado contra el motor destino.

Las sentencias se aplican una a una, con commit tras cada una, por una sola conexión (el SET search_path de pg_schema afecta a las siguientes). Las sentencias que solo contienen comentarios (rutinas sin cuerpo, miembros de PACKAGE) no se envían.

Parameters:

Name Type Description Default
target_connection Any

SyncDatabaseManager del motor destino (o un Engine de SQLAlchemy). Un objeto que solo ofrezca execute_custom_one(sql, params) se usa sentencia a sentencia con ese método.

 required
audit_sink AuditSink | None

Destino opcional del rastro de auditoría (:mod:util_bbdd.audit): los avisos del plan, un evento statement por sentencia (posición, primera línea, duración, error) y un evento run de cierre, todos con el mismo run_id. Si el plan está bloqueado por avisos ERROR se registran los avisos y el run fallido. Un fallo al escribir en el destino no interrumpe la ejecución (se registra como ERROR). None (por defecto): sin rastro, como siempre.

 None

Raises:

Type Description
ValueError

Si el plan tiene uno o más warnings de severidad ERROR (self.error_count > 0). No hay flag de override: resuelve los errores del plan (revisa self.warnings) antes de ejecutar, o usa emit_ddl()/emit_statements() para inspeccionar el DDL sin ejecutarlo.
DatabaseOperationError

Si una sentencia falla; indica su posición y su primera línea. Las anteriores quedan aplicadas.

Examples:

>>> from util_bbdd.audit import MemoryAuditSink
>>> sink = MemoryAuditSink()
>>> plan.execute(target_manager, audit_sink=sink)
>>> [e.status for e in sink.events() if e.kind == "run"]
['ok']

audit_events() ¶

Los avisos del plan como eventos de auditoría (plan_warning), para escribirlos en un AuditSink.

Examples:

>>> sink.write(plan.audit_events())

validate_views(target_connection=None, *, include_tables=True, audit_sink=None) ¶

Valida las vistas del plan en el destino sin dejar cambios.

En PostgreSQL y SQL Server (DDL transaccional) crea las tablas del plan (si include_tables) y cada vista en una transacción que se deshace. En MySQL, MariaDB y Oracle (el DDL hace commit implícito) solo comprueba la sintaxis con sqlglot; sin sqlglot no valida.

Parameters:

Name Type Description Default
target_connection Any

SyncDatabaseManager (o Engine de SQLAlchemy) del destino; obligatorio con destino PostgreSQL o SQL Server.

 None
include_tables bool

Crear también las tablas del plan en la transacción (validar antes de execute).

 True
audit_sink AuditSink | None

Destino opcional de auditoría: un evento view_validation por vista (ok, failed o skipped). Un fallo al escribir en el destino se registra como ERROR y no cambia el resultado.

 None

Returns:

Type Description
list[Any]

list[ViewValidationResult]: Una entrada por vista con SQL (view, valid, method, error).

MigrationWarning¶

Aviso generado durante la planificación o la emisión del DDL.

Attributes:

Name Type Description
table str

Tabla, vista o rutina afectada.
column str | None

Columna afectada, si la hay.
category WarningCategory

Clase de aviso (:data:WarningCategory).
target_type str

Tipo, nombre o etiqueta en el destino (depende de la categoría): el tipo destino en TYPE, el nombre nuevo en IDENTIFIER, una etiqueta legible en el resto. Para filtrar, usar category y code.
message str

Explicación legible.
severity WarningSeverity

INFO, WARNING o ERROR (un ERROR impide MigrationPlan.execute).
source_type str | None

Tipo de datos en el origen, cuando el aviso trata de uno (TYPE, DEFAULT, AUTO_INCREMENT).
proposals tuple[str, ...]

Alternativas propuestas.
code WarningCode | None

Subtipo estable del aviso (:data:WarningCode, 0.22.0); None en los de tipos e identificadores.
